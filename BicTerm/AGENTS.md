## CONVENTIONS (deltas from root)
- Every WindowGroup in BicTermApp must mirror the UI-test gate (comment in file).
- Explicit user choices persisted struct-over-UserDefaults (same convention as `HerdrClipboardSettings`); absent key = no explicit choice, heuristic applies.
- `Info.plist` here is GENERATED by the xcodegen `info:` block — edit project.yml, never this file.

## ANTI-PATTERNS (dir-specific)
- No SSH/protocol/business logic in this layer — that belongs in BicTermCore.
- Terminal mouse/selection/clipboard behavior belongs in the Vendor/SwiftTerm fork (record hunks in its patch doc), not here.
- Accessory UI must never cover the terminal's bottom row.

## NOTES
- Toolbar heuristic: default HIDDEN when `GCKeyboard.coalesced != nil` (hardware keyboard), visible for on-screen keyboard. `hardwareKeyboardAttached` is injectable for unit tests. Explicit toggle choice (top-right keyboard icon, UserDefaults) beats the heuristic.
- Strip is in-layout: terminal shrinks, never overlays; `inputAccessoryView` dock is deliberately NOT used (iPad hardware-keyboard case).
- `TerminalViewCache.swift` keeps Terminal views alive across SwiftUI rebuilds.
- Terminal/ contains preview + test-only files (PreviewFixtureSupport, TestHardwareKeyInjector) — keep them out of production paths.
